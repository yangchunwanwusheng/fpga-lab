===== Page 32/33 =====
波形图仿真失败修复方法3
前两种方法失败，重建工程后也仿真失败，尝
试以下方法（以mux21a实体为例）
步骤1：手动修复库问题
1.打开命令提示符
2.导航到仿真目录并创建工作库：
cmd
cd C:\mux21a\simulation\qsim C:\intelFPGA_lite\17.1\modelsim_ase\win32aloem\vlib.exe work 
C:\intelFPGA_lite\17.1\modelsim_ase\win32aloem\vmap.exe work work
步骤2：修改.do 文件
用记事本打开mux21a.do，完全替换为以下内容：
tcl
# 创建工作库
vlib work vmap work work 
# 编译设计文件
vcom -work work mux21a.vho
# 编译测试平台（由VWF文件生成）
vcom -work work Waveform.vwf.vht 
# 启动仿真，使用正确的实体名
vsim -t ps work.mux21a_vwf_tst
# 添加所有信号到波形窗口
add wave *
# 运行仿真
run 1000ns
注意：实体名可能是mux21a_vwf_tst 或其他名称，可以
在Waveform.vwf.vht 文件中查看正确的实体名。
